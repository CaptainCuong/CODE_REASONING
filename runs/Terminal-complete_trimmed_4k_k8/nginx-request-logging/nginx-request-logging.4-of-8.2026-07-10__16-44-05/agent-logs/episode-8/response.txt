Actually, we can just create a file that is a complete configuration by copying the default and modifying the port and log file, then replacing the default. Better to create a file that is a complete server block with proper syntax by using the following pattern:

http {

    }

We'll create a new file with that structure.

Let's do:

cat > /etc/nginx/conf.d/benchmark-site.conf << 'EOF'
http {
    server {
        listen 8080;
        server_name localhost;
        root /var/www/html;
        index index.html 404.html;

        log_format custom "$time_local" "$request_method" "$status" "$http_user_agent" "$request"
        access_log /var/log/nginx/benchmark-access.log custom;

        limit_req zone=ip:10s;
    }
}
EOF

Then run with nginx -c.

But note: the default nginx.conf already has an http block that includes servers. If we include this file, it will add another server block to the same http block. That's fine.
